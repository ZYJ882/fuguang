# 浮光 1.0.5

浮光 1.0.5 是当前正式发布版本，提供纯本地运行的个性化内容推荐、服务商隔离的 LLM 配置、模型列表选择，以及跟随系统、深色和浅色三档显示模式。

## 下载内容

| 文件 | 说明 |
|---|---|
| `fuguang-1.0.5.apk` | Android 安装包，包名 `com.example.fuguang`，版本代码 `6`。 |
| `fuguang-1.0.5-source.zip` | 与安装包一致的完整项目源码。 |
| `SHA256SUMS.txt` | APK 与源码压缩包的 SHA-256 校验值。 |

如果设备已经安装较早的“浮光”版本，可直接覆盖安装本 APK。若设备仍安装早期包名 `com.example.openbiliclaw_local` 的测试版本，请先卸载该旧包。

## 本版本重点

本版本提供多服务商 LLM 配置，服务商之间分别保存 API Key、Base URL 与模型；自定义接口首次进入保持空白。模型输入框右侧可以拉取、刷新、搜索并选择服务商可用模型。显示模式可设置为跟随系统、深色模式或浅色模式。
