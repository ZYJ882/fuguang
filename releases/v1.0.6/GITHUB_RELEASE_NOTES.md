# 浮光 1.0.6

浮光 1.0.6 新增 B 站登录入口，支持二维码扫码登录和手动 Cookie 登录；同时保留多服务商 LLM 配置、模型列表选择，以及跟随系统、深色和浅色三档显示模式。

## 下载内容

| 文件 | 说明 |
|---|---|
| `fuguang-1.0.6.apk` | Android 安装包，包名 `com.example.fuguang`，版本代码 `7`。 |
| `fuguang-1.0.6-source.zip` | 与安装包一致的完整项目源码。 |
| `SHA256SUMS.txt` | APK 与源码压缩包的 SHA-256 校验值。 |

如设备已经安装较早的“浮光”版本，可直接覆盖安装。若设备仍安装早期包名 `com.example.openbiliclaw_local` 的测试版本，请先卸载该旧包。

> 本版本按用户要求保留了 B 站扫码登录模块。登录凭证属于敏感信息，请勿分享 Cookie 或 access token。
