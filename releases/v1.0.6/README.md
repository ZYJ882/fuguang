# 浮光 1.0.6 发布文件

本目录包含可直接安装的 Android APK 与对应版本的完整源码压缩包。

| 文件 | 说明 |
|---|---|
| `fuguang-1.0.6.apk` | Android 安装包，包名为 `com.example.fuguang`，版本名 `1.0.6`、版本代码 `7`。 |
| `fuguang-1.0.6-source.zip` | 与该 APK 对应的完整源码压缩包。 |
| `SHA256SUMS.txt` | 两个发布文件的 SHA-256 校验值。 |

如果设备中已安装同一包名的较旧版本，可直接覆盖安装；若设备仍保留早期 `com.example.openbiliclaw_local` 包名的测试版本，请先卸载旧包。

本版本新增 B 站扫码或 Cookie 登录入口。Cookie、access token 等均属于敏感凭据，请勿与他人分享。
