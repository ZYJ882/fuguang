# 浮光 1.0.7

浮光 1.0.7 扩展了 B 站登录入口，支持账号密码、短信验证码、二维码扫码和 Cookie 登录。账号密码或短信登录触发平台安全校验时，应用会显示极验验证页面，由用户亲自完成验证后继续操作。

## 下载内容

| 文件 | 说明 |
|---|---|
| `fuguang-1.0.7.apk` | Android 安装包，包名 `com.example.fuguang`，版本代码 `8`。 |
| `fuguang-1.0.7-source.zip` | 与安装包一致的完整项目源码。 |
| `SHA256SUMS.txt` | APK 与源码压缩包的 SHA-256 校验值。 |

如设备已经安装较早的“浮光”版本，可直接覆盖安装。若设备仍安装早期包名 `com.example.openbiliclaw_local` 的测试版本，请先卸载该旧包。

> 登录凭据、Cookie、短信验证码与安全验证结果均属于敏感信息，请仅在本人设备上使用，切勿分享给他人。
